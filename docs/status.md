  **A second lesson from the same hour, and it is not about line endings at all.** The script that corrupted `test_litigation.py` also carried a `str.replace()` whose pattern no longer matched, because an earlier edit had inserted a comment line into the text it was matching on. `replace()` returns the string unchanged when it matches nothing, so the script printed its success message and did nothing — and the assertion it was supposed to add was silently absent, which is why a mutation test then *passed* and briefly appeared to prove the opposite of the truth. **A no-op edit reports success**, exactly as a zero-expected grep returns zero. The standing rule already covers the grep case; it extends verbatim here: any scripted substitution must assert the pattern was present before writing. The mutation script in the same session did carry that guard and behaved correctly, which is the controlled comparison.
